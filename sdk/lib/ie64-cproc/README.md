# IE64 freestanding C compatibility runtime

`crt0.s` and `libie64c.c` belong to the `ie64-unknown-none` bare-metal C
toolchain. They are not an IntuitionOS runtime and make no system calls.

V2 normally assembles `crt0.s` to `crt0.o` and links it with the Picolibc
sysroot. The linker defines the image, BSS, heap and stack boundaries. The CRT
uses the fixed stack interval `[0x8F000, 0x9F000)`, rejects insufficient
visible RAM, clears BSS, runs initialisers, calls `main`, and calls `exit`.

`libie64c.s` is deliberately generated, not checked in as hand-written
assembly. It is generated by `ie64-cproc -S libie64c.c` from the current IE64
cproc and QBE implementations. It remains a source-compatible fallback for
development fixtures; installed V2 links use Picolibc and `libatomic.a`.
