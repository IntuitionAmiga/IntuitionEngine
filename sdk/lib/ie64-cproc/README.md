# IE64 freestanding C support

`crt0.s` and `libie64c.c` belong to the `ie64-unknown-none` bare-metal C
toolchain. They are not an IntuitionOS runtime and make no system calls.

The driver emits `org 0x1000` before `crt0.s`, appends all user units, appends
this library's generated assembly, then emits `__ie64_heap_start`. The CRT
uses the fixed stack interval `[0x8F000, 0x9F000)` and halts before `main` when
`CR_RAM_SIZE_BYTES` is smaller than `0x9F000`.

`libie64c.s` is deliberately generated, not checked in as hand-written
assembly. It is generated by `ie64-cproc -S libie64c.c` after the IE64 cproc
and QBE slices exist. Until that point this C source is the library authority.
