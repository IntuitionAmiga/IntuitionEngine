# Alien Breed 3D II for Intuition Engine

This archive contains four single-file builds of Intuition Engine. Each build
contains one embedded, self-contained AB3D2 IE68 image. No additional asset
directory is required.

| Executable | Description                                 |
|---|---------------------------------------------|
| `IntuitionEngine-AB3D2-linux-amd64` | Original AB3D2 for 64-bit Linux             |
| `IntuitionEngine-AB3D2-windows-amd64.exe` | Original AB3D2 for 64-bit Windows           |
| `IntuitionEngine-AB3D2-Karlos-TKG-High-linux-amd64` | Karlos' Redux High AB3D2 for 64-bit Linux   |
| `IntuitionEngine-AB3D2-Karlos-TKG-High-windows-amd64.exe` | Karlos' Redux High AB3D2 for 64-bit Windows |

## Controls and display

Player 1 joystick or joypad game controllers are supported alongside keyboard
and mouse controls.

The Guest-Advanced CRT filter is off by default. F7 cycles through flat, curved
and off. F11 toggles between stretch-fill and aspect-fit
where applicable, while Shift+F11 toggles fullscreen mode.
F12 toggles the status bar; it is visible by default, so the first press hides
it.

Intuition Engine is the home computer that never was: a free and open-source
demoscene platform and home computer with six CPU architectures sharing one
bus and the same hardware devices. It is designed for writing and running
games and demos in BASIC, assembly and C.
